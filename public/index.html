Help and safety

Load forecast reuses a fresh cache and asks the provider only when needed. Refresh forecast forces provider access and requires Signal K read/write or admin permission. Source, fetched time, freshness, cache state and any offline fallback remain visible above the table.

Forecasts are planning aids. Verify the selected location, age, provider and conditions against appropriate official information before making operational decisions.
